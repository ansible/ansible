fact_caching_version_invalidation
---------------------------------

Default: True

When enabled, Ansible will include the running core version in cache keys used by the fact cache plugins. This prevents reuse of cache entries generated by older or incompatible Ansible core versions.

Example ansible.cfg snippet to disable:

[defaults]
# Disable version-based cache key prefixing (share cache across versions)
fact_caching_version_invalidation = false

Notes:
- This setting is enabled by default to be safe and avoid subtle bugs when cache schemas change between core versions.
- The cache key prefixing strategy is used to auto-invalidate old entries; no explicit cache cleanup is required when upgrading Ansible.
